## 内容安全覆盖

- 严格 Frontmatter，真实日期，slug 与文件名一致
- 可执行 YAML 引擎、别名、自定义标签、重复键与未知字段拒绝
- 原始 HTML、JSX、ESM、MDX 表达式拒绝；代码块仅作为文本展示
- 外部链接协议、凭据 URL、编码路径与路径穿越检查
- 本地图片大小、文件签名、替代文字、存在性与符号链接边界
- MP4/WebM 本地视频大小/签名/路径、语音字幕要求、VTT 内容及 PDF/TXT 附件检查
- 草稿与待审内容不会进入公开路由和搜索；公共媒体本身仍为公开文件
- draft → review → published 门槛与 `--approve`；私有本地预览隔离
- 重复标题与生成目录 ID 碰撞处理

## 明确未完成的验证

当前环境未能完成真实浏览器截图或交互验收：

1. 云工作区已安装的 Chromium 无法启动，操作系统拒绝其 singleton socket；使用允许的执行路径重试后仍失败
2. 受支持的云浏览器明确阻止访问本地预览 URL，返回 `ERR_BLOCKED_BY_CLIENT`

因此没有桌面/手机真实截图，不把生成的 hero 图或样例视频当作截图，也不声称完成逐像素验收、浏览器控制台检查、键盘端到端测试或完整可访问性审计。响应式断点、可见焦点、减少动态效果、Radix 对话框行为已实现并通过类型/构建，但仍需在可访问预览的浏览器中确认。

建议首次在可用浏览器中执行：

- 1440×1000、1024×768、390×844、320px 宽度与 200% 缩放
- 所有导航和深链接；前进/后退；文章目录锚点
- Cmd/Ctrl+K、搜索无结果/清空、Esc、再次打开与焦点返回
- 主题筛选、URL 查询参数、列表搜索和空状态
- 手机导航打开、选择、关闭、再次打开
- 视频播放/暂停/拖动/字幕；文章表格和代码块不撑出屏幕
- 系统 reduced-motion；无错误日志、没有不必要的外部资源请求
