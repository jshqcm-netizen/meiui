# 第三版：玻璃工作台

基线为 GitHub main `04cf1c05ed5dcdd9c6d7ccdff4db56e23e0d788a`，开始前重新取回并逐项验证 103 个源文件。所有迭代都基于这个完整版本。

## 设计方向

重新对照四张实际参考图后，采用 Streamxy 的胶囊控制栏、Casado 的异形模块比例，以及两张智能家居作品的透光层次和环境反射。保留 qcm.dev 的技术笔记语境，不添加虚构使用量、气温、活跃用户或进度。

- 浅色：蓝灰环境、霜白面板、深蓝正文，边缘高光清楚但克制
- 深色：石板蓝玻璃、雾蓝文字、柔和蓝色操作态，阅读面板保留充足不透明度
- 原创摄影质感的磨砂玻璃背景提供实际材质纹理；与原有钴蓝玻璃主视觉分层使用
- 外层工作台、侧栏、工具栏和阅读面板使用不同厚度/透明度，避免一排相同的卡片
- 保留一个低强度指针高光；尊重减少动态效果，不增加循环动画

参考链接与版权边界仍见 [设计说明](DESIGN.md)。新背景独立生成，不复制参考作品的摄影、头像、场景或 UI。

## 增量 1：明暗主题与磨砂材质

使用 next-themes 和已有 Radix ToggleGroup 实现可键盘操作的浅色/深色选择，选择只保存在本机浏览器。明确的 data-theme 选择器统一 Tailwind 状态，避免系统外观与手动选择混用。

正文、次要文字、操作态、弹层、代码块和三类应用卡片统一到语义令牌；阅读内容有近乎实色的表面。主题测试直接读取实际配色并计算两套颜色在主要实色表面的对比度。没有把源码测试等同于浏览器视觉验收。

通过官方 CLI 安装并审阅 Tabs、Accordion、Select、Input，为后续的首页与内容浏览增量提供组件基础。原有组件未被强制覆盖。

## 增量 2：更完整的内容浏览

- 手记页增加最新文章摘要；文档页提供实际存在的入门指南与首主题分组
- 主题胶囊展示真实篇数，搜索支持中文、全角字符与多关键词交集
- shadcn Select 提供最新、最早、最短阅读时间、标题四种排序；ToggleGroup 切换网格/列表
- 保留主题深链接与其他查询参数；空结果可重置；初始 HTML 已包含实际文章链接
- 只向客户端传递公开内容的展示元数据，草稿、待审条目和正文不会混入统计

## 增量 3：首页和应用空间

首页将原有钴蓝视觉与真实精选文章结合，增加阅读书架 Tabs 和主题入口。书架的文章数量、示例提示与链接都从内容文件计算。

应用空间增加主站与三个规划入口的域名关系图、Accordion 常见问题与分层规划说明。图中的子域名只链接到本站介绍页；页面明确说明当前没有线上后台、账户、模型调用或运行中的智能体。

## 增量 4：可访问性修正与交付检查

静态复核发现并修正了浅色未选中书架标签和深色选中文字的对比问题。回归检查读取实际 CSS 令牌，覆盖两套实色表面，以及黑/白背景极值经环境、工作台和面板透明度合成后的文字对比；这属于颜色公式验证，不等同于像素采样或全面 WCAG 审计。

- 完整内容校验、TypeScript、ESLint、47 项单元测试、生产构建通过
- 16 个导出 HTML、511 个站内链接/资源、目录锚点、初始内容链接与规划入口检查通过
- 10 个 HTTP 路径、404、HEAD 和视频 Range 206 通过；运行时依赖审计 0 个已知漏洞
- 两套实色表面次要文字最低对比度：浅色 6.15:1、深色 5.71:1；透明层保守边界内三种正文/链接色最低为 4.68:1、6.75:1
- 浏览器测试扩展到 12 个场景、3 个视口，共发现 36 个项目用例；修正单选 ToggleGroup 实际为 radio 的定位方式，并通过服务端组件渲染测试验证

## 仍需真实浏览器验收

本次重新尝试后，Chromium 仍被运行环境拒绝创建 socket；受支持的云浏览器也阻止访问本地预览地址。因此没有真实桌面/手机截图，没有声称浏览器交互、剪贴板、控制台或逐像素验收通过。没有通过隧道或公开部署绕过该限制。

在可用的本地浏览器中运行 `npm run test:ui`；另外检查 320px 宽度、200% 缩放、明暗主题持久化、键盘 Tabs/Accordion、排序弹层和原生媒体。生产发布前仍需审核示例内容、托管响应头与 noindex。
