# 第三版：玻璃工作台

基线为 GitHub main `04cf1c05ed5dcdd9c6d7ccdff4db56e23e0d788a`，开始前重新取回并逐项验证 103 个源文件。所有迭代都基于这个完整版本。

## 设计方向

重新对照四张实际参考图后，采用 Streamxy 的胶囊控制栏、Casado 的异形模块比例，以及两张智能家居作品的透光层次和环境反射。保留 qcm.dev 的技术笔记语境，不添加虚构使用量、气温、活跃用户或进度。

- 浅色：蓝灰环境、霜白面板、深蓝正文，边缘高光清楚但克制
- 深色：石板蓝玻璃、雾蓝文字、柔和蓝色操作态，阅读面板保留充足不透明度
- 原创摄影质感的磨砂玻璃背景提供实际材质纹理；与原有钴蓝玻璃主视觉分层使用
- 外层工作台、侧栏、工具栏和阅读面板使用不同厚度/透明度，避免一排相同的卡片
- 保留一个低强度指针高光；尊重减少动态效果，不增加循环动画

参考链接与版权边界仍见 [设计说明](DESIGN.md)。新背景独立生成，不复制参考作品的摄影、头像、场景或 UI。

## 增量 1：明暗主题与磨砂材质

使用 next-themes 和已有 Radix ToggleGroup 实现可键盘操作的浅色/深色选择，选择只保存在本机浏览器。明确的 data-theme 选择器统一 Tailwind 状态，避免系统外观与手动选择混用。

正文、次要文字、操作态、弹层、代码块和三类应用卡片统一到语义令牌；阅读内容有近乎实色的表面。主题测试直接读取实际配色并计算两套颜色在主要实色表面的对比度。没有把源码测试等同于浏览器视觉验收。

通过官方 CLI 安装并审阅 Tabs、Accordion、Select、Input，为后续的首页与内容浏览增量提供组件基础。原有组件未被强制覆盖。
